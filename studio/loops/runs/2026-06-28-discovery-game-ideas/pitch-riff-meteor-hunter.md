# Riff A — **Skyfall Rangers** *(recommended meteor hunter)*

**One sentence:** A cozy hilltop observatory; when a meteor shower starts, you **read the tracker**, **sprint to the predicted tile**, and **net the fall** before it buries — then haul fragments to the **Specimen Lab**.

| | |
|---|---|
| **Core verb** | **INTERCEPT** (position + timing, not idle collect) |
| **First 5 min** | Tutorial shower: one slow green meteor → map shows landing circle → run → hold net at impact → *clunk* → fragment in bag → lab microscope adds **Starfall Codex** entry #1 |
| **First hour** | Unlock **Tracker Tier 2** (30s more warning); **Magnet Cart** auto-hauls from nearby tiles; **Iron Shower** event (rare metals); open **East Ridge** landing zone |
| **Why tomorrow** | Shower calendar (real in-game night cycle); codex sets (Perseids, Geminids themes); upgrade **net size** and **tracker range** |
| **Co-op** | **Split roles:** friend on radio (calls bearings), you on field (net) — or swap. Solo: **Auto-Beep** earpiece (earnable) gives audio cue for bearing |
| **Solo-not-lonely** | Observatory NPCs; server **Shower Intensity meter**; async **fragment postcards** |
| **Monetization** | All nets/trackers earnable; Robux = Ranger coins, private server |
| **v1 slice** | One hill + East Ridge, 3 shower types, 12 codex entries, Iron Shower stub |
| **Roblox check** | Meteor *themes* exist (disaster sims, space shooters); **cozy intercept + catalog lab** on a pastel hill not found in quick scan |

**Sell line:** *You're not grinding a field — you're hunting the sky when it falls.*

# Riff B — **Crater Courier**

**Core verb:** **EXCAVATE** — Meteors already fell overnight; morning map shows **new craters**. Hike out with tools, **dig gently** (don't crack specimen), **courier** back to town observatory on a balance board or cart.

**Hook:** Wizard Tycoon expedition + gentle archaeology. Less twitch, more exploration.

**Risk:** Could feel slow if dig minigame isn't juicy.

---

# Riff C — **Meteor Market Night**

**Core verb:** **APPRAISE** — Town night market; meteors land in a **perimeter field** during event windows. You **find**, **brush**, **identify** at your stall, NPC collectors bid. Shopkeeper loop + treasure identity.

**Hook:** Curio Counter cousin but sky-timed drops instead of alley dig.

**Risk:** Overlaps storefront sims if not differentiated by **live shower events**.
