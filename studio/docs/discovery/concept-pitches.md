## Archive — Iteration 1 detail (superseded by iter 2 active set above)

### 1. Chime Orchard

**One-liner:** Walk a pastel wind orchard and collect shimmering **tone shards** when chimes ring — fill your melody codex, upgrade chimes, attract breeze-sprites that ring distant rows for you.

**Core loop (solo or 2P co-op):**
```
Stroll orchard rows → wind triggers chimes → collect tone shards →
complete melody patterns in codex → sell duplicate tones →
upgrade chime sets + orchard plots → unlock new wind biomes
```

**Bee Swarm mapping:**
- **Fields** = orchard rows (each row has a pentatonic "mood")
- **Collectors** = breeze-sprites (auto-trigger chimes in assigned rows)
- **Quests** = NPC Listener Bears want specific 3-note sequences
- **Events** = Wind Festivals (server-wide gusts boost rare harmonic shards)

**Why it fits EP brief:**
- **One core verb:** collect tones
- **Cozy pastel:** bamboo chimes, peach-blossom trees, soft sky gradients
- **Not lonely:** NPC listeners applaud completed melodies; 2P **duet co-op** (each player triggers half the chimes in a row); async melody gift postcards
- **Fair F2P:** all chimes earnable; Robux = breeze coins only
- **Novel on Roblox:** wind chimes exist as decor elsewhere; no tone-collection sim found

**Novel twist:** Completing a codex melody permanently changes ambient music in your orchard plot.

**Risks:** Audio mixing must feel soothing not noisy; cap simultaneous chime voices.

### 2. Driftbell Valley

**One-liner:** Plant pastel **pinwheel collectors** in breezy meadows — when they spin, they drop drift tokens you gather to craft bigger pinwheels and unlock windier valleys.

**Core loop (solo or 2P co-op):**
```
Plant pinwheel → wait for wind / run to spin it → collect drift tokens →
craft new pinwheel designs → pinwheels passively spin when you're away →
sell spare tokens → expand meadow plots → reach new wind tiers
```

**Bee Swarm mapping:**
- **Fields** = meadow plots (wind tier gates which pinwheel sizes work)
- **Collectors** = pinwheels themselves (passive token generation while spinning)
- **Quests** = Windmill Keeper NPCs request specific pinwheel color sets
- **Events** = Gust Days (global wind direction rotates; bonus token drops)

**Why it fits EP brief:**
- **One core verb:** collect drift tokens (via pinwheel spins)
- **Cozy pastel:** candy-striped pinwheels, rolling hills, cotton-cloud sky
- **Not lonely:** 2P co-plant (friend places pinwheels on your adjacent plot edge); Wind Festival group goals; async pinwheel design gifts
- **Fair F2P:** all pinwheel tiers earnable
- **Novel on Roblox:** no dedicated pinwheel-field collector sim found

**Novel twist:** Pinwheel patterns form visible **crop-circle mandalas** on your plot — social flex without PvP.

**Risks:** Must avoid feeling like a reskin of generic clicker sims; pinwheel visuals carry identity.

### 3. Snowglobe Shelf

**One-liner:** Shake cozy **snowglobes** on your bedroom shelf — each shake releases miniature scene fragments to collect; complete globes to unlock new shelf rooms and diorama biomes.

**Core loop (solo or 2P co-op):**
```
Pick globe → shake → catch floating scene fragments →
slot fragments into globe template → complete globe →
display earns sparkle tokens → buy new empty globes + shelf expansions →
deeper diorama themes unlock
```

**Bee Swarm mapping:**
- **Fields** = shelf rooms (each room is a progression zone)
- **Collectors** = completed globes (passively drip sparkle tokens while displayed)
- **Quests** = Curator Mice want specific diorama themes completed
- **Events** = Blizzard Nights (rare fragment types only during gentle indoor snow FX)

**Why it fits EP brief:**
- **One core verb:** collect fragments (via shake)
- **Cozy pastel:** miniature dioramas, warm lamplight, soft snowfall inside glass
- **Not lonely:** NPC shelf visitors comment on favorite globes; 2P **co-shake** (both shake same mega-globe for bonus fragments); async globe trading board (cosmetic swaps only)
- **Fair F2P:** all globes earnable
- **Novel on Roblox:** snowball rolling sims exist; snowglobe fragment codex not found

**Novel twist:** Each completed globe is a tiny explorable diorama you can **peek into** (short camera zoom) — collectible + display trophy.

**Risks:** Miniature art scope; v1 ships **one shelf room + 12 globe templates** before expanding.
