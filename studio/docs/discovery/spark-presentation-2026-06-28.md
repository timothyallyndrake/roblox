# 1. Skyfall Rangers — *Meteor Hunter*

**One line:** When the shower alarm pings, read the tracker, sprint to the landing circle, and **net the fall** before it sinks — then catalog fragments in your hilltop **Specimen Lab**.

### Why this isn't Meteor Simulator

[Meteor Simulator](https://www.roblox.com/games/9602700094/TECH-Meteor-Simulator) = you **throw** meteors to **destroy** objects for cash.  
Skyfall Rangers = you **catch** what the sky drops. Opposite fantasy.

### Core loop

```
Shower forecast → map shows ETA + tile → intercept with net →
lab clean/catalog → sell duplicates → upgrade tracker/net/ridges →
next shower tier
```

### First 5 minutes

Dusk hilltop. Tutorial **Green Trail** meteor (slow, loud ping on tracker). Circle appears on grass. Run. Hold net at impact. *Thunk.* Fragment in bag. Lab microscope: **Codex #1 — Pebble Spark**. Second shower unlocks **East Ridge**.

### First hour

- **Tracker Mk2** (+20s warning)
- **Magnet Sled** hauls from 2 tiles away
- **Iron Shower** event (48h window, rare metals)
- **Lantern Sprite** pet nets one slow meteor per shower while you're on West Ridge

### Skill + chill balance

- **Rally Kart moments:** sprint + timing
- **Bee Swarm retention:** events, upgrades, codex sets, offline capped drip from lab samples

### Co-op (optional)

**Spotter + Ranger:** friend on observatory deck calls bearing ("East! 8 seconds!"); you net. +25% rare fragment chance. Solo: **Beep Ear** upgrade (earnable).

### Solo-not-lonely

Observatory NPCs, server **Shower Intensity** meter, async **fragment postcards**.

### Fair F2P

All nets, ridges, codex earnable. Robux = Ranger coins, private server.

### v1 vertical slice

Hilltop + East Ridge, 3 shower types, 15 codex entries, Iron Shower stub, 1 Lantern Sprite.

### Risks

- Must feel **cozy**, not disaster — soft impacts, no craters hurting NPCs
- Shower schedule = content cadence (weekly calendar)

### Self-score: **8.78**

# 2. Curio Counter — *Treasure + Shopfront*

**One line:** Dig muddy curios in the alley patch, **scrub** them at your sink, tag a price, stock the front window — browsers buy while you dig the next hole.

### EP fit

Direct answer to **Q28 treasure hunt + storefront** — not a reskin of Hearth & Haul's co-op haul; **shop-first** with micro-dig.

### Core loop

```
Dig patch → scrub minigame → price tag → window shelf →
NPC purchase → codex set rewards → deeper dig layer unlock
```

### First 5 minutes

Muddy brooch → scrub (hold in sweet spot) → 10 coins → window slot → mouse NPC buys → **Back Alley** dig spot opens.

### First hour

### Co-op

# 3. Bounce Barn — *Physics Joy Break*

**One line:** Roll hay bales (then watermelons, yarn balls…) down the barn hill through **color gates** for combo stamps — spend stamps on sillier balls and hill modules between runs.

### EP fit

**Plane Crazy + Rally Kart** in your library — this is the **skill break** between sim grinds, not another collector field.

### Core loop

```
Pick ball → roll downhill → steer through gates → combo multiplier →
stamps → unlock balls + hill modules → longer run next time
```

### First 5 minutes

One hay bale, one hill, three gates. Miss one gate — still get stamps. Buy **Wide Bale**. Second hill module: **S-curve**.

### First hour

Unlock **Watermelon** (wobble physics), **Night Hill** (glow gates), daily **Stamp Challenge** route.

### Co-op

**Co-roll:** two balls released on countdown; gate pairs need both colors hit within 2s.

### Why Roblox gap

Obby rollers exist; **combo stamp barn meta** with upgradeable hill + ball roster as primary sim hub is less crowded.

### Self-score: **8.68**

# 4. Switchboard Town — *Cozy Utility Puzzle*

**One line:** A tiny town asks for **power** (light the bakery, spin the ferris wheel). You flip **cable switches** on a wall board to route current from the windmill — wrong route = gentle fizzle, right route = NPC cheer + **Town Token**.

### Why I kept it

Breaks audio/chime/plant/meteor entirely. **Puzzle sim** with readable cause-effect. Thumbnail: glowing switch wall + happy bakery.

### Core loop

```
Request card (Bakery needs 2 yellow) → flip switches on board →
test button → tokens → unlock new districts + switch types (splitter, timer)
```

### First 5 minutes

One windmill input, three switches, bakery request. Flip-flip-test. *Ding.* Tokens. **Fountain** district card appears.

### Co-op

**Split board:** each player owns half the switches; requests need both halves.

### Self-score: **8.61** — slightly niche, but **most novel** mechanic in the deck
