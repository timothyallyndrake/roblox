# Cosmic Bloom — Tutorial And Naming Family Test

**Date:** 2026-07-01
**Input source:** [`notebooklm-family-overview.md`](./notebooklm-family-overview.md) + GDD §2.1 tutorial beats
**Status:** Desk-read complete; live family answers still required before Phase 04/06 sign-off.

---

## Purpose

This gate checks whether kids and family reviewers understand the first session, like the names, and notice any unfair or stressful-feeling mechanics before implementation starts.

The live test may trigger immediate pre-build renames. If a kid says a name is confusing, too babyish, or sounds unfair, treat that as valid data, not as a debate to win.

---

## Read-Aloud Script

Use the NotebookLM audio overview first, then read this short tutorial sequence:

1. You arrive in your meadow and meet the Constellation Keeper.
2. The Keeper gives you a Glow Mote seed.
3. You plant Glow Mote in your garden.
4. You use moonlight to help it grow.
5. You harvest Glow Berries and Glow Mote pollen.
6. You bring Glow Berries to the Orbital Outpost.
7. You launch a capsule to feed planet friends on Lumina.
8. You earn Cosmic Coins.
9. The Keeper gives you Moon Melon and Nebula Sprout seeds.
10. You plant them and harvest their pollen.
11. You use the Stellar Nursery to mix Glow Mote pollen and Moon Melon pollen.
12. You discover Starlace Vine.
13. Your Bloomdex lights up its first star.
14. The Keeper says, "The meadow is yours. Feed the stars."

---

## Live Test Questions

Ask these without explaining the intended answer first:

1. What do you think you do first when the game starts?
2. What do you think Glow Mote is?
3. What do you think the Orbital Outpost is for?
4. What do you think the Stellar Nursery is for?
5. What do you think the Bloomdex is?
6. Would you want to keep playing after the first Bloomdex star lights up?
7. Which name sounds coolest?
8. Which name sounds too little-kid or silly?
9. Which name is hard to understand?
10. Does Community Table sound fun or like a chore?
11. Does Cosmic Spin sound fair?
12. Does Extra Garden Beds sound like a fair helper or like paying to win?
13. Does Private Meadow sound safe and cozy?
14. What part should happen sooner?
15. What part would you remove?

## Desk-Read Findings

This is a proxy check, not a replacement for live kid feedback.

| Area | Finding | Action before live test |
|------|---------|-------------------------|
| Tutorial order | Clear enough when read as a story. | Keep current tutorial flow. |
| First action | "Plant Glow Mote" is obvious. | Keep. |
| Orbital Outpost | Understandable if paired with "feed friendly planets." | Always pair in kid-facing copy. |
| Stellar Nursery | Strong name; likely understandable with "mix pollen." | Keep. |
| Bloomdex | Strong collection hook; explain once as plant collection book. | Keep. |
| Sun Rawr | Highest naming risk; intentionally silly. | Keep on watchlist; test against "Sun Roar" and "Sunmane" if kids object. |
| Planet Friends Fed | Wholesome but slightly long. | Keep on watchlist; explain as "how many planet friends you helped." |
| Prize Bloom | Works if "display trophy" is repeated. | Keep; never describe as sellable. |
| Community Table | Safer than "Feed" for pressure. | Keep; use potluck language. |
| Extra Garden Beds (+2) | Needs fairness framing. | In family copy, say "two extra plant beds; same seeds, same gates." |
| Cosmic Spin | Must avoid casino energy. | Emphasize earned tokens, one daily free spin, cosmetic prizes, server fairness. |

---

## Pass Criteria

- At least one kid can explain the first action without help.
- At least one kid can explain Bloomdex after one explanation.
- No tested name gets repeated "too babyish" or "I don't get it" reactions.
- Extra Garden Beds does not read as required to have fun.
- Cosmic Spin does not read as real-money gambling.
- Community Table reads as helping, not pressure.
- Private Meadow reads as safety/family comfort, not easier rewards.
